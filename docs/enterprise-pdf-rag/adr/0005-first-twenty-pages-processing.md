# ADR 0005 — Process physical pages 1–20 with scoped evidence qualification

Status: Accepted for the user-requested processing milestone, 2026-09-19.

The selected AIA source remains the immutable 71-page source snapshot. This phase processes physical pages 1–20 only, reusing its stored SVG and text observations. A separate processing manifest records `source_page_count`, `selected_pages`, stage attempts, actual artifact references, qualification and concrete failures. Saved source pages are not counted as semantically processed pages. Pages 21–71 receive no new model processing.

Source Canonical observations and inferred layout remain separate. Canonical records preserve the source page, exact text occurrences, coordinates and native graphics asset. Layout enrichment identifies objects of type Text, List, Table, Chart, Diagram, Image, Formula or Group, with source references and producer provenance. Each selected object must have its actual typed IR and description, or a named stage failure; an empty pending artifact cannot count as completed processing. Chart objects reuse the existing `ChartIR` rather than introduce a second chart schema.

Both chart branches receive the same versioned SVG representation and its derived model view. A raster view is an input aid with that SVG's digest and rendering fingerprint; it does not replace the stored SVG. Native visual completeness, exact source-byte identity, text occurrence authenticity and semantic field/relationship qualification are distinct. Model output starts inferred. Two model outputs agreeing, or a high confidence score, cannot grant qualification.

The figure boundary adds optional source-observation provenance on SVG evidence and optional chart title, period and marks. Existing request fields stay unchanged. SVG, ChartIR and description content identities explicitly advance to v2 because their immutable content schemas changed; old artifacts are not rewritten in place. The frozen response schemas are reviewed for these additions rather than silently accepting drift.

FigureBundle also gains an optional qualification receipt ID, null for existing explicit demo receipts. Bundle content identity advances to v2. This additive response field is intentionally frozen in the v1 HTTP schema; it does not change request compatibility or permit unqualified production answers.

Production admission requires an independent, scoped receipt binding the complete source, SVG version, field paths, exact occurrences and their relationship to a mark, category, period and unit. Wrong marks, swapped periods, duplicate labels and incorrect units must be rejected. Claims with all necessary fields qualified may form a description retrieval projection. Other inferred IR and descriptions remain saved for review with specific diagnostics; they cannot support verified numerical answers. The existing explicit demo receipts and tests remain isolated.

Only eligible natural-language description/text projections enter the real, independently configured local embedding service. ChartIR and raw SVG never enter that port. A hit resolves its bound ChartIR and evidence inside the same immutable processing snapshot. Missing or mismatched dependencies fail closed without summary fallback. Processing fingerprints include input artifact IDs and producer/prompt/renderer versions; actual model output bytes have their own content IDs. Reusing a fingerprint is a cache lookup, not a claim of deterministic model output.

This phase implements one-machine processing and local manifest activation, not distributed publication, universal uploads, ACL, or a general agent platform. Offline TDD and the complete `bash scripts/ci.sh` gate precede a bounded live pilot, then the selected-page run. Model failures remain explicit and do not trigger an offline-demo or cloud-embedding fallback.

The explicit `source-labels-only` policy implements the PRD's limited-description allowance without granting numerical qualification. It selects only pre-existing independent description claims that exactly match one source text occurrence and contain no numbers or currency/percentage signs. It clears all inferred relation fields. Its scoped receipt binds the source, same SVG and raw branch closure. The retrieved chart projection has no axes, points, period, title or marks and remains PENDING; the complete raw ChartIR is retained separately for review. Financial-question guards reject this scope unconditionally. This is a separately selected policy, not an automatic fallback from the stricter donut relationship verifier.

Before local publication or hydration, the application reconstructs the SVG/model view from the pinned source and repeats the selected qualification. Page-context observations are checked against that source separately from mark evidence. A retrieval snapshot binds descriptions, qualification policy, model fingerprint, dimensions, raw branch lineage and immutable index members. Source or semantic closure failures leave the current pointer unchanged. The same source with changed descriptions or qualifications produces a new retrieval snapshot.

Empty parent Groups retain actual child references and a separate source-region transcription with PENDING grouping semantics. They are not forced into the literal-qualified index. Reviewed layout corrections preserve the raw model layout, rule/version and original object kind/bounds. Replaying cached model JSON may repair a mapper and create new typed artifacts; it does not modify the raw response or make another model request. A rejected source digest is never rewritten to manufacture a successful branch.
